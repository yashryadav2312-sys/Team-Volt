# Thermoelectric Peltier Cooling System ❄️

## 📌 Overview

This project demonstrates a **thermoelectric cooling system using a TEC12706 Peltier module**. It provides an eco-friendly alternative to conventional refrigeration by eliminating harmful refrigerants.

---

## 🎯 Problem Statement

Traditional refrigeration systems are bulky, consume high power, and release harmful gases.
This project aims to design a **compact, energy-efficient, and eco-friendly cooling system**.

---

## ⚙️ Components Used

* TEC12706 Peltier Module
* Heat Sink (H410R)
* Cooling Fan (PWM)
* Arduino Uno
* DS18B20 Temperature Sensor
* W1209 Temperature Controller
* 12V DC Power Supply

---

## 🔧 Working Principle

* Based on **Peltier Effect** (heat transfer using electric current)
* One side becomes cold, other becomes hot
* Heat is removed using heat sink + fan
* Arduino monitors temperature and controls system

---

## 📊 Results

* Achieved temperature difference of **40–60°C**
* Cold side reached **0–3°C within 5 minutes**
* Improved efficiency using PWM control
